## ⭐ Projet phare : Cachkey

<table>
<tr>
<td>

**Vos secrets. Votre maîtrise.**

Les clés d'API, mots de passe et fichiers `.env` d'une équipe, chiffrés et partagés proprement, sur votre propre serveur.

- 🔐 Valeurs chiffrées (AES-256-GCM, une clé par projet)
- 👥 Accès par projet et par environnement, journal d'activité
- 💻 CLI façon `gh` : `cachkey login`, `pull`, `run`
- 🔑 Jetons d'accès en lecture seule et API publique pour la CI
- 🐳 Images Docker multi-architectures, Docker Compose, templates Dokploy et Coolify
- ✅ Tests e2e Playwright et revue de sécurité

**Stack :** Bun · TypeScript · TanStack Start · Elysia · Better Auth · Prisma · PostgreSQL · Docker

[Voir le dépôt →](https://github.com/Joyboy-dy/cachkey) · Licence AGPL-3.0
